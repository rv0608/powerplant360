# PowerPlant360 Lite V1.3

## New in V1.3
- Drag/drop uploaded files immediately appear in the document table.
- Clean start: demo rows removed.
- Category column.
- Document type column.
- File size.
- Upload date/time.
- 100% complete status.
- Edit file name/category/document type.
- Delete file.
- Filter by category.
- Filter by document type.
- Search by filename.
- Basic automatic category/type guessing from the file name.

## Still Lite / local-only
The app stores metadata in browser LocalStorage only.
The selected file contents are not permanently stored.
PDF/Word/Excel contents are not yet indexed or searchable.
The next backend phase will add secure storage, extraction, indexing and source/page references.
